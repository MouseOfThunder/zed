Agent Crate Architecture

crates/agent — Der AI-Agent-Layer von Zed

Layer-Stack

Entry Point
agent.rs — Public API & Re-Exports
Root-Modul. Exportiert Thread, Tools, Permissions, Templates, NativeAgentServer. Bindet Context-Server und ACP-Thread-Protokoll ein.
acp_thread context_server language_model
Core Runtime
thread.rs — Agent-Thread & Turn-Loop
Zentrale Laufzeit: Message-Historie, Completion-Loop, Tool-Dispatch, Compaction, Cancellation. >8000 Zeilen — das Herz des Agenten.
tools tool_permissions templates sandboxing agent_settings
Persistence
db.rs — SQLite Database
Speichert Threads & Messages persistent via SQLite. Wird von thread_store.rs verwaltet.
sqlite acp_thread
Thread Management
thread_store.rs — Thread Store
Verwaltet alle Agent-Threads: Laden, Speichern, Serialisierung. Brücke zwischen Thread-Laufzeit und DB.
db thread
Tools Layer
tools.rs — Tool Registry & Feature Flags
tools!-Makro registriert 23 Built-in-Tools. Feature-Flag-Gating für LSP, Rename, Subagent-Tools. Template-Generierung für Model-Schema.
feature_flags terminal_tool edit_file_tool ...
Security
tool_permissions.rs — Permission Engine
Hardcoded Security Rules + Regex-basierte Allow/Deny/Confirm-Matrix. Sandbox-Authorization. Symlink-Escape-Detection.
agent_settings shell_command_parser
Sandbox
sandboxing.rs — macOS Seatbelt Integration
OS-Level Sandbox für Terminal-Kommandos. Feature-Flag-gesteuert. Netzwerk/FS-Write-Permission-Escalation.
feature_flags sandbox
Prompting
templates.rs + templates/ — Handlebars Templates
System-Prompt, Edit-File-Prompt, Diff-Fenced-Format. Handlebars-Rendering mit Projekt-Kontext, Tool-Liste, Skills.
handlebars agent_skills
External Interface
native_agent_server.rs — ACP Server
Implementiert das Agent-Client-Protocol (ACP). Verbindet Native UI mit Agent-Backend. Session-Management.
acp_thread thread_store
Utility
outline.rs + pattern_extraction.rs
File-Outline-Generierung für Read-File-Tool. Pattern-Extraction für Edit-Sessions und Code-Analyse.

Turn Execution Flow

1
Build Request
System-Prompt + Messages + Tools → LanguageModelRequest. Auto-Compact-Prüfung.
2
Stream & Dispatch
LLM-Stream → Parse Tool-Calls → Permission-Check → Run Tools. Parallel für independent scopes.
3
Loop or End
Tool-Results → nächste Iteration oder EndTurn/Refusal/MaxTokens. Retry-Logik.
